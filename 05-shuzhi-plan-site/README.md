# 数智治途 · 大学规划导航站

![Builder](https://img.shields.io/badge/构建-Codex%20CLI-7768AE)
![Pages](https://img.shields.io/badge/页面-11%2B-informational)
![License](https://img.shields.io/badge/License-MIT-informational)

用 **Codex CLI** 构建的大学四年规划导航站：围绕"数智治途"（数字公共治理专业）主线，
把宏观规划、专业解读、学分政策、分阶段行动手册与五条目标路线（保研/班长/荣誉/调选/学分）
组织成一个 11+ 页的静态站点，并另附单文件合并版。

## ✨ 页面结构（与站点导航一致）

| 页面 | 内容 |
|------|------|
| 首页 index.html | 总览入口 |
| 宏观规划 guihua-daxue.html | 四年总体路线图 |
| 专业解读 zhuanye-jiedu.html | 数字公共治理专业拆解 |
| 大一行动手册 xingdong-dayi.html / 大三行动 | 分年可执行清单 |
| 目标路线 ×5 | 保研 · 班长 · 荣誉 · 调选 · 学分政策，每页附"查看路线" |

## 📁 两种形态

- `site/` — 多页完整版（页面间互相跳转，便于持续扩充）；
- `数智治途单文件版.html` — 458KB 合并版，单文件即可分享/离线查阅。

> **隐私提示**：站内含真实学籍信息（姓名/学号/学院等），面向公众展示或开源前请先将此类信息脱敏。

## 🚀 使用

双击 `site/index.html` 或直接打开单文件版。
