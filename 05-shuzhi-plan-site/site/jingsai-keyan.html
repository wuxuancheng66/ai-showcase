竞赛与科研

保研看绩点，更看"作品"。竞赛与科研是把知识变成成果的两条主赛道——也是你区别于其他人的关键。

大一参加调研项目打底 → 大二拿下数据分析大赛 + 大创立项 → 大三进课题组 + 科研训练出论文 → 大四毕业论文收尾。步步为营，四年后你的简历会自己说话。

四、如何进课题组（邮件模板）

第一步：准备——查老师主页了解研究方向，读 1-2 篇TA的论文，准备一页简历（成绩+技能+兴趣）。

第二步：发邮件（模板如下，注意简洁具体、不要群发）：

主题：请教科研机会-吴宣澄-2026级数字公共治理

X老师您好：
我是政务学院2026级数字公共治理专业本科生吴宣澄（学号26••••••30），
阅读了您关于数字政府/数据治理的论文《...》，对您的研究方向非常感兴趣。
我目前掌握 Python 基础与数据分析（正在学习计量与机器学习），
也想在数字治理方向做一点研究。
想请问老师近期是否有本科生可以参与的研究/调研项目？
我每周可投入约X小时，可先承担数据整理、文献梳理等基础工作。
随信附上我的简历与课程成绩，期待您的回复，谢谢老师！
顺祝 教安
吴宣澄

第三步：跟进——3-5天未回复可礼貌再发一次；被拒也正常，换老师继续。多问几位。

五、备赛方法：组队 · 选题 · 时间线

组队：找什么人？ ▶

一个能打的队伍 = 数据分析担当 + 公共政策担当 + 表达/文案担当 + 汇报担当（可以身兼多职）。你学数字公共治理，天然是"政策+数据"的桥梁，适合当队长或数据分析主力。组队优先找：数学/统计好的、会 Python 的、写作强的、口才好的同学，跨专业组队更出彩。

选题：怎么选不踩坑？ ▶

原则：小切口、有数据、能讲清"治理故事"。三个方向供参考——① 数字政府：如"某地政务 APP 使用率分析"；② 公共服务：如"智慧社区养老服务的满意度研究"；③ 政策评估：如"数据要素政策文本分析"。避开没数据、没意义、太宏大的题。

时间线：从 9 月到决赛怎么排？ ▶

9月组队定题 → 10月数据收集与清洗 → 11月分析与可视化 → 12月初稿 → 次年1-2月打磨报告 → 3月提交 → 4-5月答辩/决赛。每周固定一次小组会，用飞书/腾讯文档协作，AI 用来辅助清洗代码和报告润色（分析必须自己懂）。

大创申报书写作要点 ▶

大创（大学生创新创业训练计划）是保研履历硬通货。申报书写四件事：① 选题依据（为什么要做，1-2 段讲清价值）；② 研究内容与方法（具体做什么、用什么方法，越具体越好）；③ 创新点（和已有研究比新在哪）；④ 预期成果（报告/论文/数据产品）。12 月启动推荐前，提前 1 个月和老师沟通选题，用 AI 帮你改语言但不替你思考。
