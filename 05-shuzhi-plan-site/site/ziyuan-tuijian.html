资源推荐

只收数字公共治理相关的学习资源：编程数据、AI 工具、公共治理与政策、经典教材、竞赛社区。每一条都配了"怎么用"，按需取用、循序渐进。

💡 使用原则
① 先从"必备"开始，不要一次囤太多；② 工具类只从官网或官方应用商店下载，陌生链接一律不点；③ 资源是弹药，行动才是武器——每个资源都要对应一个本周小任务。

编程与数据

Python 入门 · 廖雪峰教程 必备

中文免费、从零到进阶最顺的 Python 教程。配合《Python基础与数据分析》课（大一下）使用，开学前先过一遍基础语法。

菜鸟教程 辅助

速查手册型网站，忘了语法随时查。适合"边写边查"。

中国大学 MOOC（Python 数据分析） 必备

国内权威 MOOC 平台，搜"Python数据分析"有大量国家精品课，跟着做项目比只看书快。

pandas / matplotlib 官方文档 查用

数据分析两大核心库的官方文档就是最好的教程。做课程项目时优先查官方示例。

Jupyter Notebook / VS Code 必备

写数据分析代码的 IDE。VS Code 在校园正版软件平台可免费获取，配合 AI 插件效率翻倍。

Kaggle / 和鲸社区 进阶

真实数据集与比赛平台。大二参加数据分析大赛前，先在上面复现 1-2 个入门项目（如泰坦尼克号预测）。

Excel 进阶视频教程 必备

政务场景里 Excel 比 Python 更常用。你 Safari 里已经收藏了完整教程，大一暑假系统性刷完，函数+透视表+图表即可。

AI 工具

🔒 安全提示
AI 工具一律从官网或官方应用商店下载；涉及学号、成绩、身份证等个人隐私的信息绝不输入非官方 AI；下载/安装任何软件前先核验来源与稳定性。

ChatGPT 必备

通用问答、写作、编程、规划全能。学习用：让 AI 当"私教/批改教练/出题官"（提示词见 AI 工具箱页）。

DeepSeek 必备

中文理解强、免费额度友好。适合深度阅读、政策文本分析、长文档整理。

Z.ai（智谱 GLM） 常用

国产大模型，中文场景表现好，支持智能体。你已收藏其开放平台，可试着搭"数字治理问答助手"。

Kimi 常用

长文档阅读神器，一次读几十页论文/政策文件并总结，写文献综述时很好用。

扣子（Coze） 进阶

低代码搭 AI 应用。大二做"AI+数字治理"项目时，用它搭政务问答/政策解读 Bot 很出彩。

AI 搜索（Perplexity 等） 辅助

带引用来源的 AI 搜索，查政策、查数据、查论文时能直接给出处，写作业可溯源。

公共治理与政策

知网 / 万方 必备

论文数据库，校园网/VPN 免费。写课程论文、做文献综述的起点。先从"数字治理""数字政府"关键词检索。

国家统计局 / 地方政府数据开放平台 必备

做数据分析项目的真实数据源。政务数据开放平台有大量公共数据，是课程项目和大赛素材库。

政务学院公众号 / 教务处公众号 必备

学院通知、讲座、竞赛、推免信息的第一手来源。入学后第一时间关注并置顶。

中国公共管理研究中心 常用

教育部人文社科重点研究基地，依托中大政务学院。网站有学术动态、报告和讲座信息。

国务院 / 广东省政府官网政策文件库 常用

练政策敏感性：每周精读 1 份与数字政府/数据要素相关的政策文件（如"数字中国建设整体布局规划"），用政策分析框架拆解。

公共管理学报 / 中国行政管理（期刊） 进阶

本学科顶级期刊，大二起每月读 1-2 篇摘要，培养"研究问题"的感觉。

经典教材

夏书章《行政管理学》 必备

中国公共管理领域发行最广的教材，获全国优秀教材一等奖。大一《行政管理学》课就用它，认真精读。

《数字治理：理论、方法与案例》类入门书 必备

配合《数字治理概论》课（大一下）阅读，建立"数字政府-数据治理-算法治理"整体框架。

公共政策分析教材 常用

大二《公共政策导论》配套。推荐结合"多源流框架""政策评估"等概念学习。

《Python 编程：从入门到实践》 必备

最适合新手的 Python 书，项目导向。与课程同步或假期自学皆可。

《利用 Python 进行数据分析》 进阶

pandas 圣经。大二做计量/数据分析项目时按需查阅。

政府工作报告 / 五年规划 必备

不是教材但胜似教材：每年政府工作报告是政策敏感性的最佳训练材料，精读并做框架笔记。

竞赛与社区

粤港澳大学生公共治理数据分析大赛 必备

学院联合港城大、澳大主办，每年 9 月启动。数字公共治理方向第一大赛，大二必参加（详见竞赛科研页）。

挑战杯 / 中国国际大学生创新大赛 必备

国家级 A 类竞赛，保研加分含金量高。前一年 11 月启动报名。

政务关注·全国社会调研大赛 常用

学院品牌赛事（已办 19 届），调研方向，配合"青年中国说"项目。

全国高校模拟市长大赛 常用

情景式治理竞赛，练公共表达与治理思维，对班长/选调面试都有帮助。

GitHub 常用

代码作品集平台。大学期间把 Python/数据分析项目都传上去，保研/求职时直接甩链接。

知网研学 / Zotero 辅助

文献管理工具，写论文整理参考文献必备，越早用越省事。
