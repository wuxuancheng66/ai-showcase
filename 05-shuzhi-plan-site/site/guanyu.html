关于本站

这个站是做什么的、怎么用、资料从哪来、有哪些要注意的地方——看完这页，你会比绝大多数同学更会「用」自己的大学规划。

一、站点说明 · 这是你的私人导航站

「数智治途」是吴宣澄为中山大学数字公共治理专业四年大学生活搭建的个人规划站，目标只有一句话：把教务系统里冷冰冰的培养方案，翻译成看得懂、能执行、可勾选的学习与成长路线。

它不是一个「内容平台」，而是一张为你定制的作战地图。全站 21 个页面，按「规划 → 课程 → 行动 → 目标 → 工具 → 复盘」组织：宏观规划负责「看全貌」，课程地图和学分政策负责「懂规则」，四本行动手册负责「按月执行」，五个目标页负责「逐项攻破」，AI 工具箱和资源推荐负责「提效」，里程碑复盘负责「回头看」。下面这张页面地图，就是全站的目录索引。

🔒 关于隐私，放心用
本站是纯静态网页，双击 index.html 即可离线打开，不联网、不收集任何数据。你勾选的打卡清单只保存在你自己浏览器的本地存储（localStorage）里，换浏览器或清理缓存后会重置，属正常现象，不是数据丢了。

为什么叫「数智治途」？「数智」对应专业的两块基石——数据（数据分析、AI 技术）与智能治理（数字政府、算法治理）；「治途」则是一语双关：既指「治理之路」，也指「求学之途」。这个名字本身就是对这个专业的一句话总结：用数据与智能，走好治理与成长的路。

二、使用指南 · 三分钟上手

1. 导航怎么用

左侧边栏是全站的「总目录」，按栏目分组：起步 / 宏观规划 / 专业与课程 / 行动手册 / 目标专区 / 资源与工具 / 复盘与关于。当前所在页面会高亮显示，一眼就能看出「我在哪、还有哪些地方没去过」。手机等窄屏设备上，点左上角「☰」按钮可以呼出侧栏，点任意菜单项会自动收起，不用担心挡住内容。

2. 打卡清单怎么用

各行动手册、目标页、本页底部都有可勾选的清单（li > label > input[type=checkbox]）。勾选后，卡片顶部的进度条会实时更新，刷新页面、下次打开浏览器，勾选状态依然保留。建议：每周一打开当周行动页，把本周要做的勾掉；月末回看完成率，低于 60% 就说明计划排得太满，需要减量。

3. 课程地图怎么用

课程地图收录了培养方案全部 99 门课。顶部筛选标签可以按「公共必修 / 专业核心 / 实践课 / 通识平台 / 专业选修模块」切换，右上角搜索框支持按课程名、课程编码、任课教师模糊搜索；筛选与搜索可以组合使用，方便快速定位「这学期要上的课」和「某个老师的课」。看到想选的课，记下课程编码，选课时直接搜。

4. 其他小功能

  • 思维导图：宏观规划页的思维导图节点可点击折叠/展开，先看主干再看分支，避免信息过载。
  • 折叠面板 / 标签页：部分页面用它们收纳长内容，点标题或标签即可展开，不用滚动很长一页。
  • 主题与返回顶部：右下角「🌙」切换深色/浅色主题（会记住你的选择，夜里复习不刺眼）；「↑」一键回到页首。
  • 相对路径：全部页面互相用相对路径链接，整个文件夹拷到 U 盘、换电脑，双击即可用，不依赖任何服务。
🧭 推荐的阅读顺序
第 1 周：首页 → 宏观规划 → 专业解读。第 2-4 周：大一行动手册逐周推进。之后按需查阅课程地图、学分政策和五个目标页。每学期末回来做一次里程碑复盘——规划的意义在「回头看」里才会显现。

使用本站时请记住它「轻」在哪、也「重」在哪：轻，是因为它只是整理的二手材料，官方永远是一手；重，是因为它把 99 门课、145.5 学分、四年节点压缩进了你随时能打开的一张地图。别让这份地图替你思考——让它帮你在正确的时间，思考正确的问题。

四、免责声明 · 请认真读一遍

⚠️ 培养方案以教务处最新为准
本站引用的是 2026 级培养方案的整理版本，尽管已尽量与原文核对，但选课要求、学分结构、开课安排、保研与荣誉学士政策都可能调整。做任何重要决定（选课、转专业、申报项目）前，请以教务系统、学院通知和官方文件为准；本文档与官方文件冲突时，听官方的。绩点、排名、入党名额这类信息，永远以辅导员和学院公布的为准。
🔗 外链安全提示
本站为纯静态页面，原则上不放外部链接；若个别页面提到资源网站或公众号，仅作推荐。访问任何外部链接前，请留意：① 优先使用学校提供的正版软件与数据库（知网、万方等经校园网免费）；② 不向任何「需要交钱」「索要学号密码」的第三方提供信息；③ 遇到要求立即转账、缴费的「竞赛/培训/中介」通知，先找辅导员核实。大学里最贵的不是学费，是信息差——但防骗的意识比信息更贵。
🤖 AI 使用红线（本站立场）
本站鼓励用 AI 当「学习教练」：讲题、批改、出题、规划、模拟面试。但作业、论文、考试必须自己完成，AI 生成内容按学校规定标注，重要政策条文与数据务必回到原文核验。学术不端会直接毁掉保研资格，这条红线碰不得。记住一句话：AI 能帮你把路走得更快，但方向要你自己定。

最后再补一句实在话：本站所有内容都建立在「公开信息 + 个人经验」之上，不是官方承诺。它最大的价值不是准确到小数点，而是提醒你在什么时候该去查什么、该做什么——具体数字永远以官方为准。

五、常见问题

🛡️ 一个原则：冲突时听官方的
如果本站内容和教务系统、学院通知、辅导员说法不一致，一律以官方为准，并在复盘里记录差异。规划站的价值是「提前提醒、降低信息差」，而不是「替代官方」。把「哪个数字过时了」记下来反馈，站就会越来越准。
为什么不用在线网站，而要做成纯静态 HTML？▶

因为「随时可用、永远属于自己」。双击就能打开，不依赖服务器，不怕平台关停，本地存储的打卡数据也完全私有。对个人规划来说，「稳定可回看」比「花哨的交互」重要得多。

打卡数据会丢吗？换电脑怎么办？▶

数据存在浏览器的 localStorage 里，清理缓存、换浏览器或换电脑都会重置。建议每学期末把里程碑复盘里的进度抄进自己的笔记软件（如 Obsidian），既留档，也方便写复盘。

这些页面会更新吗？▶

会。随着选课真实反馈、政策调整和你的实际经历，课程地图会补入选课建议，行动手册会加入真实踩坑记录。发现过时或错误的内容，记下来反馈即可——规划是活的，不是刻在石头上的。

我该多久看一次这个站？▶

开学和选课季前看「课程 + 学分」页，每周看当月的「行动手册」，每个目标推进前看对应「目标页」，每学期末做一次「里程碑复盘」。不用天天刷——它的正确用法是「需要时查，关键时勾」。
