  • 数据来源：2026 级数字公共治理专业培养方案，共 99 门课：公共必修 21 门 + 学分必修 1 门（艺术与审美课）、专业核心 21 门、实践课 3 门、通识平台 6 门、专业选修 47 门。

  • 筛选：每次点击一个标签即切换筛选条件（单选）。「通识平台」标签只显示 6 门平台必修课（政治学原理、行政管理学、高数 I/II、中国政府与政治、概率统计）；想看选修再点下方具体模块标签。

📊 三个节奏启示
① 大二是"最轻却最该发力"的窗口：课程少，正好用来把 Python 练熟、进课题组；② 大三课程最密集，选修要提前到大二下开始消化，别全部堆在峰值期；③ 大四反而清空，留给实习、论文和荣誉课程——所以路径 4 的专选务必在大三下之前修完。
🎯 大一新生优先关注课程

大一上：高等数学三（I）4 学分（绩点命脉）· 大学英语 2 · 军事课 4 · 政治学原理 3 · 行政管理学 3 · 经济学基础 3 · 理解数字时代：智能体与公共管理 0.5（接触老师）

大一下：高等数学三（II）4 · 数字治理概论 2（专业第一课）· Python 基础与数据分析 2（编程起点）· 社会科学研究方法 3 · 宪法与行政法 3 · 中国政府与政治 3

优先级建议：高数 > Python > 数字治理概论 > 英语 > 其他。前两门定绩点，中间两门定专业方向。

五个选修模块解读

专业选修按五大模块组织，对应不同的能力方向和出路。以下按"培养什么能力 / 适合谁 / 推荐选哪几门"逐张解读，选课前建议先读一遍。

🧭 30 秒定位
想做监管规则 → 模块 1；想做政策研究 / 智库 → 模块 2；爱看城市与社区 → 模块 3；铁了心读研 / 冲荣誉学士 → 模块 4；理科背景、想当"懂技术的治理者" → 模块 5。混搭公式：主模块修满 ≥12 学分，再从相邻模块挑 2-4 学分，竞争力最强。

培养什么能力：理解"数字时代政府怎么监管"——平台经济与数字战略、数字化协同治理、廉政与治理、公共财政与税收等。本质是训练你站在"规则制定者"视角思考：新技术出现后，制度该怎么跟进、怎么约束、怎么平衡。

适合谁：想走体制内监管 / 政策岗、目标考公选调的同学，或想做"治理规则"研究的人。和你"政策 + 技术"双线里的政策线最贴近。

推荐选（与路径 1 和选调最相关）：数字战略管理（2，大二下，吴少龙）、数字化协同治理（2，大三上，陈琤）、廉政与治理（2，大三上，朱琳）、公共财务管理（2，大三上）、国家发展（2，大四上，梁平汉）。

适合谁：想走政策研究、智库、保研公共政策方向的同学。领域知识越广，分析越有底气。

培养什么能力：研究生水平的经典阅读与研究方法——公共管理经典与前沿、政治理论专题研究、伦理分析与公共政策、高级统计、高级政策分析。这是荣誉学士学位的核心课程来源：修 ≥18 学分荣誉课程且主修 + 荣誉课均绩 ≥3.5，即可冲击荣誉学士学位。

适合谁：打算保研 / 读研、想冲荣誉学位的同学。大四再修，但学分规划要提前留好空间。

推荐选：公共管理经典与前沿（3，大四上，齐云蕾）、伦理分析与公共政策（2，大四上，朱佳峰）、高级统计（2，大四下，王秋石）、高级政策分析（2，大四下，陈娜）。

课程学分学期老师

培养什么能力：最硬核的技术模块——田野调查（质性数据）、传播数据分析、博弈论、实验公共管理、数据库原理、科研训练。训练你从"拿数据"到"分析数据"再到"做实验 / 做科研"的完整技术链路。

适合谁：理科背景、目标"懂技术的治理者"、保研走实证 / 数据方向的同学——就是为你设计的模块。

推荐选（按时间线）：田野调查方法（2，大一下，夏循祥）→ 传播数据分析基础（3，大二下，陈湘萍）→ 数据库原理及应用（2.5，大三下，张青年）→ 博弈论（2，大三上，何俊志）→ 实验公共管理（2，大三下，张书维）→ 科研训练与创新实践（2，大三下，李棉管）。

组合建议：技术课打底 + 政策课补脑。路径 4 要求专选 ≥12，这里选满 12-14 学分，再留 2-4 学分给模块 1 或模块 2，形成"技术为主、政策为辅"的混搭竞争力。

🧭 模块与目标的对应
  • 目标中央选调 / 考公：模块 1（监管）+ 模块 2（政策）为主，模块 5 的技术课当加分项。
  • 目标保研 / 荣誉学士：模块 4（本研贯通）必选 ≥18 学分，模块 5 补研究方法。
  • 目标"懂技术的治理者"（推荐）：模块 5 打底 + 模块 1 / 2 各挑 1-2 门，兼顾稀缺性与体制适配。
