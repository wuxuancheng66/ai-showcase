## 查看与运行

直接打开 `index.html` 可浏览；本机完整预览可在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8765`。各项目的依赖、启动方式和限制见各自说明。Python 后端、桌面应用和 Next.js 平台无法在 GitHub Pages 上运行。

`16-quota-radar/src`、`17-mansea/src`、`19-governance-lab/src` 保存经过筛选的可移植源码，分别对应额度工具、离线手册检索和治理文本研究原型；不包含运行账户、日志、生成报告或语料全文。

班级平台源码与资料、完整个人规划仍在私有仓库。公开展示使用合成内容或功能介绍。主题收集器的展示入口使用离线演示模式，不读取团队数据；实际协作需要主动连接自己的 GitHub 授权。

## 本轮验证

18 个展示入口、搜索筛选、预览关闭和焦点返回、无 JavaScript 导航均通过浏览器检查；主要页面在 320 / 375 / 414 / 768 像素宽度下没有横向溢出。班级平台另有 媒体权限与业务单元测试和隔离数据库浏览器回归。单词本、雅思评分与录音兼容、番茄钟计时和 PPT 演示模式完成针对性检查。

未调用付费模型或操作真实团队数据；额度工具的生产后端、桌宠安装包和 Agent 完整模型流水线未在本轮重新运行。手册、日报与赛事信息请结合日期和官方来源使用。
