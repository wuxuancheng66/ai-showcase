# 军事理论备考笔记 · 2026 整合版（交互增强版）

军事理论课的全栈式备考应用：把 **教材章节知识梳理 + 1856 题全库 + 模拟考试 + 错题本/收藏夹**
整合进一个 2MB 的自包含 HTML 文件——零依赖、离线可用、双击即学。

## ✨ 功能一览（与实际界面一一对应）

- **章节知识库**：第一章 中国国防、第三章 军事思想 …… 第七章 主观题速成与答题模板，卡片式知识点全部展开/收起自由切换；
- **刷题模式**：全库 1856 题随时开刷（章节练习/随机刷题/模拟考试三模式），「再来一组」随机组题；
- **模拟考试**：整卷作答 → 提交答案 → 核对答案 → 自动评分（A+ 等级）→ 查看错题回顾 → ↻ 再做；
- **错题本 & 收藏夹**：错题自动归集，支持「重做全部错题 / 重做收藏题」，一键清空重置；
- **主观题速成**：答题模板与速成技巧专章。

## 🚀 使用

双击 `军事理论备考笔记（2026整合版·交互增强版）.html` 即可，无需联网、无需安装。
做题记录保存在浏览器本地（localStorage），可随时「清空做题记录」重置。

## 🛠 技术实现

由 Python 流水线构建：`parse_*.py` 从 Word 题库文档解析出结构化 JSON（q200/q900/terms/exams），
`assemble_v4.py` 将界面模板与应用逻辑装配为单文件产物（构建源码另存于工作区，本合集收录最终成品）。
