# WordVault · 我的单词本

![Builder](https://img.shields.io/badge/构建-Coze%20扣子-6b5bff)
![Type](https://img.shields.io/badge/类型-单文件背单词应用-ff69b4)
![License](https://img.shields.io/badge/License-MIT-informational)

用扣子 Coze 生成的单文件背单词应用（216KB 自包含）：双击即用、离线可背，
与雅思知识站（项目 03）的单词模块互补，构成"查询整理 → 专项记忆"的词汇学习链路。

## ✨ 特点

- **零依赖**：单 HTML 文件，无安装、无联网要求；
- **本地运行**：学习记录保存在本机浏览器，不上传任何服务器；
- **已核验干净**：无统计脚本、无追踪器、无内嵌个人数据（2026-09-11 扫描）。

## 🚀 使用

双击 `WordVault单词本.html` 即可开始。
