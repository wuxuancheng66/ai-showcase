额度雷达将 AI 模型价格、免费渠道状态与本机助手管理放在同一处。每条信息保留来源与验证时间，帮助你判断下一次调用该如何选择。

此页为静态介绍，不连接你的电脑，也不展示账户余额、访问令牌或本机日志。完整看板需要在自己的环境运行。

从选型到运行

查看价格变化与场景推荐，筛选可用渠道，再根据实际安装情况配置本机助手。支持的提供方可读取官方余额；没有余额接口的来源会明确标为未知。估算与真实余额分别呈现。

信息会过期，依据需要留下

价格来自采集源，渠道状态来自最后一次探活，额度预测来自本机台账。推荐是辅助判断，最终价格与可用权限以提供方为准。启用密钥探活或 AI 接管前，应检查操作内容与费用。

在本机启动

需要 Python 3.12。先阅读依赖与配置说明，再在隔离环境安装。

python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn radar.web.app:app --host 127.0.0.1 --port 8000

打开 http://127.0.0.1:8000。管理端口默认只在本机使用；远程部署需按 README 配置认证与网络访问规则。

部署前查看权限

配置修改采用预览、备份、验证与失败回滚。需要实际访问账号、安装工具或发送模型请求的步骤，应先检查范围与费用。验证码、付款与权限提升需要人工处理。

项目结构与验证

radar/ 管理采集、状态与网页；config/ 是可配置的公开种子；tests/ 覆盖服务行为。环境、运行数据与输出不进入公开源码。

.venv/bin/python -m pytest tests/ -q
