# QuotaRadar · 额度雷达

自托管的模型价格、免费渠道状态、额度台账与本机助手管理工具。价格、可用性和推荐会过期；以来源与最后核验时间判断，最终以提供方为准。

## 运行

需要 Python 3.12。在此目录创建隔离环境，审核依赖与配置后自行安装：

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn radar.web.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000 。启动会创建本地运行数据并启动项目配置的后台任务；建议先检查 `radar/config.py`、`config/` 与 `radar/scheduler/jobs.py`。此公开源码不附作者账号、`.env`、数据库、运行日志或本机手册。无需凭据的页面也不代表全部外部接口可用。

本机手册默认从项目的 `manuals/` 目录查找；可用 `QR_KB_DIR` 指向你自己的目录，再在 `config/manuals.yaml` 登记文件名。请勿公开私人手册、账号或机器路径。

对外部署前必须检查管理认证、监听地址、反向代理与 TLS。涉及真实探活、AI 请求、注册或工具安装的操作，请先评估权限与费用。公开材料仅展示源码与结构，不提供公共管理后台。
