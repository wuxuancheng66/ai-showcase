PPT 自动生成器

16 页原生演示模板。先运行演示确认版式，再接入自己的素材。

无需私人素材的演示

python build_ppt.py --demo --output demo.pptx

全部图片由程序生成并标记 DEMO，不读取个人照片或聊天截图。演示沿用原模板文字，不代表素材证据。

接入自己的素材

python build_ppt.py --materials ./data/materials --masked ./data/masked --assets ./data/assets --output presentation.pptx
python build_ppt.py --check --materials ./data/materials --masked ./data/masked --assets ./data/assets

materials：IMG_5582、5584、5586、5588、5590、5591、5593、5595、5597、5599、5601、5602、5603、5604、5605、5607、5608、5610、5611、5612，均为 .jpg。

masked：masked_120.jpg、masked_121.jpg、masked_123.jpg、masked_124.jpg；请先脱敏。

assets：raft_card.png、dsh_card.png、codex_card.png。

参数

--work-dir：处理图片存放位置；--font：目标设备已安装字体；--check：检查输入；--help：全部参数。无参数运行保留原本本机默认位置，输入缺失时不会伪装成功。

当前环境需包含 python-pptx 和 Pillow。生成前检查输出路径，避免覆盖需要保留的文件。
