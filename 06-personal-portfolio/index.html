你好，我是 吴宣澄 👋

我目前是一名大一学生，就读于计算机科学与技术专业。从高中第一次接触 Python 开始，我便被编程的创造力深深吸引。进入大学后，我开始系统性地学习前端开发、数据结构和算法，并积极参与校内的 Hackathon 和技术社团活动。

我相信技术的力量在于解决问题和创造价值。课余时间，我喜欢钻研开源项目，在 GitHub 上学习优秀工程师的代码，也会写一些技术博客来记录自己的学习历程。目前正在深入学习 React 生态与 Node.js 后端开发，目标是成为一名全栈工程师。

除了写代码，我也热爱跑步、摄影和阅读科幻小说。这些爱好让我保持对世界的好奇心，也不断提醒我——最好的代码，往往诞生于清晰的头脑和充沛的体力。
