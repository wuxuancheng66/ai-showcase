# 个人作品集网站

![Builder](https://img.shields.io/badge/构建-VS%20Code-informational)
![Stack](https://img.shields.io/badge/TailwindCSS-CDN-38bdf8?logo=tailwindcss&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-informational)

个人主页/作品集网站：深色玻璃拟态设计，单页五大区块，含 3D 翻转卡片与作品轮播交互。

## ✨ 页面区块（与站点导航一致）

1. **Hero** — 首屏自我介绍；
2. **关于我** — 个人背景与经历；
3. **技能 & 技术栈** — 能力矩阵；
4. **项目作品** — 翻转卡片 + 轮播展示（hover 3D 翻转、中心放大轮播）；
5. **联系我** — 联系方式。

## 📁 内容

- `index.html` — 正式版（Inter + Noto Sans SC 字体体系，橙红主题色 #E17055）；
- `design-v2-early.html` — 早期设计变体（Noto Serif SC 衬线风格，深蓝主题），留存设计演进过程。

> 本合集根目录的 [index.html](https://wuxuancheng66.github.io/ai-showcase/) 项目展示页，即为给这个作品集配套的"项目集"延伸。

## 🚀 使用

双击 `index.html` 在浏览器打开（字体/Tailwind 走 CDN，首次打开需联网）。
