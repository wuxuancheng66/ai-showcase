紧凑型桌面番茄钟小组件：**圆形进度环 + 桌面系统通知**，纯 Python tkinter 实现，零第三方依赖。

## ✨ 功能

- 三种模式一键切换（快捷键 `1` / `2` / `3`）；
- `空格` 开始/暂停，`R` 重置，`→` 跳过当前阶段；
- 圆环进度实时渲染；阶段结束时触发 macOS/Windows 系统通知；
- 置顶小窗不挡工作区。

## 🚀 运行

```bash
python3 pomodoro_timer.py    # 无需安装任何依赖
```

macOS 首次运行需在「系统设置 → 通知」中允许 Python 发送通知。
