用 **扣子 Coze** 平台搭建的个人简介/作品集单页（297KB 自包含导出），与 VS Code 手工版
（见 06）形成"低代码平台 vs 手写代码"的双版本对照，附带 Netlify 部署二维码。

## ✨ 说明

- 由 Coze 平台生成、导出为静态单文件，无需平台即可离线打开；
- 已核验：无第三方统计脚本、无追踪器、无内嵌使用数据，为干净展示版；
- `部署二维码.png` 为 Netlify 线上部署入口的二维码。

## 🚀 使用

双击 `个人简介网站.html` 浏览；扫码可访问线上部署版本。
