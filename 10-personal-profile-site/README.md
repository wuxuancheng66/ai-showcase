# 个人简介网站 · Coze 构建版

![Builder](https://img.shields.io/badge/构建-Coze%20扣子-6b5bff)
![Type](https://img.shields.io/badge/类型-单页简介站-ff69b4)
![License](https://img.shields.io/badge/License-MIT-informational)

用 **扣子 Coze** 平台搭建的个人简介/作品集单页（单文件导出），与 VS Code 手工版
（见 06）形成"低代码平台 vs 手写代码"的双版本对照，附带 Netlify 部署二维码。

## ✨ 说明

- 由 Coze 平台生成、导出为静态单文件，无需平台即可打开；字体与 Tailwind 样式使用 CDN，完整视觉效果需要联网；
- 应用不提交表单或学习数据；外部字体及样式请求仍会连接第三方 CDN；
- `部署二维码.png` 为 Netlify 线上部署入口的二维码。

## 🚀 使用

双击 `个人简介网站.html` 浏览；扫码可访问线上部署版本。

## 无障碍操作

浏览器支持缩放。聚焦技能轮播后用左右方向键切换，也可使用上一项、下一项和圆点按钮；开启系统“减少动态效果”后停止持续背景与自动轮播。
