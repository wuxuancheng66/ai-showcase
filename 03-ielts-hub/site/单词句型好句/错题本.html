🔴 易混淆词辨析错误分类

① 形近词混淆

易混词对 区别 出错次数
affect / effect affect动词"影响"，effect名词"效果" ⏳
principal / principle principal主要的/校长，principle原则 ⏳
compliment / complement compliment赞美，complement补充 ⏳
stationary / stationery stationary静止的，stationery文具 ⏳
practice / practise practice名词，practise动词（英式） ⏳

② 近义词辨析

易混词 区别 使用场景
increase / decrease / decline increase增加；decrease减少（数量）；decline（下降/衰退，更正式） 写作Task 1数据描述
rise / raise / arise rise上升（不及物）；raise提高（及物）；arise出现（问题） 写作/口语通用
significant / substantial / considerable 都表示"大的"，significant强调重要性，substantial强调体量，considerable强调程度 写作形容词替换
comprise / consist of / constitute comprise=整体包含部分；consist of=由…组成；constitute=部分构成整体 写作Task 1描述构成

③ 动词变形规则

规则 说明 示例
重读闭音节双写 重读闭音节结尾，末尾辅音双写再加-ed/-ing drop → dropped / dropping；plan → planned / planning
以e结尾加-d 以不发音e结尾，直接加-d increase → increased；decline → declined
辅音+y改i+ed 辅音字母+y结尾，改y为i再加-ed study → studied；carry → carried
seem + 分词 seem后可接to do / 过去分词 / 形容词 seem to improve / seem improved / seem better

🟠 语法错误分类

系动词用法

错误用法 正确用法 说明
seem + 动词原形 seem + to do / 过去分词 / 形容词 seem是系动词，后接不定式或形容词性成分
It seem + adj It seems + adj / It seems that... seem要随主语人称和数变化
感官动词+动词原形 感官动词+动词原形/现在分词 see/hear/watch + do/doing 含义不同

错误类型 示例 正确用法
