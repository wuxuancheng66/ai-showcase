🎯 十大题型技巧

① 判断题（True / False / Not Given）

判断 标准 关键词
✅ True 原文明确说了，且意思一致 同义替换
❌ False 原文明确说了，但意思相反 否定词、反义词
❓ Not Given 原文没提到，或无法判断 无对应信息

⚠️ False vs Not Given 核心区别：
- False = 原文中确实有相关信息，只是和题目矛盾
- Not Given = 原文中压根儿没提这事儿

② 标题配对题（Heading Matching）

策略 说明
1️⃣ 先读所有标题，划关键词
2️⃣ 逐段阅读，先读首尾句把握主旨
3️⃣ 匹配最贴切的标题
4️⃣ 用排除法缩小范围

③ 细节配对题（Matching）

类型 策略
👤 人名-理论配对 先扫读人名（大写），定位到原文再读内容
📅 时间-事件配对 先扫读时间数字，再到原文定位
🔤 分类配对 注意选项中的核心词，回原文找对应

④ 填空题

策略 说明
🔍 预判词性 判断空格是名词/动词/形容词/数字
📍 定位关键词 用题干中的独特词定位原文
📝 注意字数限制 NO MORE THAN TWO WORDS
🔄 注意同义替换 题干和原文通常不会用完全一样的词

⑤ 选择题

策略 说明
📖 先读题干 知道要问什么再回原文找
❌ 排除法 通常能排除 1-2 个明显错误选项
🔍 定位原文 找到对应句子，仔细比对
⚠️ 注意陷阱 部分正确 ≠ 完全正确

⚡ 阅读策略

时间分配（60分钟 / 3篇文章）

文章 建议用时 策略
第1篇 15-18分钟 最简单，做得快且准确
第2篇 18-20分钟 中等难度
第3篇 20-22分钟 最难，留足时间
检查 2-5分钟 检查拼写和答题卡

高效阅读法

方法 说明
🔍 Scanning（扫读） 找特定信息（数字、人名、大写词）
👀 Skimming（略读） 快速把握段落大意，读首尾句
📖 Close Reading（精读） 理解复杂句子，分析长难句

建议做题顺序：

先看题 → 划关键词 → 回原文定位 → 精读比对 → 选出答案

🔧 长难句分析

常见结构

结构类型 示例 分析方法
🧩 定语从句 The research which was conducted by Cambridge University reveals... 找出先行词，从句是修饰
🔗 分词结构 Conducted by Cambridge University, the research... 找到主语，看分词和主语的关系
➡️ 倒装句 Not only does technology improve efficiency, but it also... 还原正常语序理解
: 冒号/分号 The findings were clear: pollution levels had increased. 冒号后是解释说明
