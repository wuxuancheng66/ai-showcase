# 雅思学习站

![Type](https://img.shields.io/badge/类型-静态知识站-9cf)
![Modules](https://img.shields.io/badge/模块-听说读写+总结体系-success)
![License](https://img.shields.io/badge/License-MIT-informational)

面向独立备考者、可离线使用和自行改编的学习资料站：以 `index.html` 为导航门户，按**听说读写**四大模块 +
**单词句型 / 每日总结 / 周报 / 月报** 组织全部备考资料，形成"输入→练习→复盘"的完整闭环。

## ✨ 亮点

- **结构化学习体系**：日报→周报→月报三层复盘机制，资料不再散落文件夹；
- **纯静态零依赖**：一个文件夹即整站，可放 U 盘/网盘/任意静态托管；
- **AI 辅助维护**：资料整理与导航生成由 AI 完成，更新成本极低。

## 📁 结构

```
site/
├── index.html        # 门户导航页
├── 阅读/ 口语/ 写作/ 听力/ 单词句型好句/
├── 每日总结/  周报/  月报/
└── 四题雅思作文.docx
```

## 🚀 使用

双击 `site/index.html` 即可浏览。

## 口语练习的实际流程

录音和练习包保存在本机；页面不会自动上传或调用评分服务。可下载后自行获取评价，再把符合字段格式的评价 JSON 导入页面。录音格式随浏览器支持选择，麦克风不可用时仍可上传音频；请及时下载备份，浏览器本地存储空间有限。

## 复用与公开内容

公开页面不预设姓名、年级、强弱科目或个人目标分数。四科知识资料中的分数与答题示例仅作为练习参考，使用者应按自己的需要选择。错题页的已填写内容和学习日志均明确标为示例，不代表新使用者的状态。

Fork或下载后，从`site/index.html`进入；可替换知识资料和复制复盘模板。口语练习记录只保存在当前浏览器，其他知识页和总结页为静态资料，不会自动保存编辑。公开包不预置任何人的真实练习历史。
