雅思备考知识库 · 静态知识站

为个人雅思备考搭建的知识库网站：以 index.html 为导航门户，按听说读写四大模块 + 单词句型 / 每日总结 / 周报 / 月报 组织全部备考资料，形成"输入→练习→复盘"的完整闭环。

✨ 亮点

  • 结构化学习体系：日报→周报→月报三层复盘机制，资料不再散落文件夹；
  • 纯静态零依赖：一个文件夹即整站，可放 U 盘/网盘/任意静态托管；
  • AI 辅助维护：资料整理与导航生成由 AI 完成，更新成本极低。

📁 结构

site/
├── index.html        # 门户导航页
├── 阅读/ 口语/ 写作/ 听力/ 单词句型好句/
├── 每日总结/  周报/  月报/
└── 四题雅思作文.docx

🚀 使用

双击 site/index.html 即可浏览。
